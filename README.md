
# Relax Map

Вебсайт для пошуку та перегляду цікавих місць для відпочинку в Україні.

## 📌 Про проєкт

Користувачі можуть переглядати статті про різні локації, ознайомлюватися з фотографіями та відгуками інших мандрівників, а також знаходити місця за назвою, типом або регіоном.

Зареєстровані користувачі можуть:
- публікувати власні місця для відпочинку;
- додавати відгуки;
- ділитися враженнями та рекомендаціями з іншими користувачами.

## 🎯 Основні функції

- 🔎 пошук місць;
- 🗺️ перегляд локацій;
- 🔖 фільтрація за категоріями та регіонами;
- ⭐ відгуки користувачів;
- 📸 фотографії місць;
- 👤 реєстрація та авторизація;
- ✍️ створення власних публікацій;
- 💬 можливість ділитися враженнями.

## 🚀 Запуск проєкту локально

1. Clone the project

```bash
  git clone https://github.com/VadymHromyk/project-favorite-01_FE
```

2. Go to the project directory

```bash
  cd project-favorite-01_FE
```

3. Install dependencies

```bash
  npm install
```

4. Create .env file in the root of the project and add the variables

5. Start the server

```bash
  npm run dev
```
